Роутер и модем

С доступом к роутеру программа видит то, что не видно с компьютера: ошибки линии, перезагрузки роутера, причину отключения от провайдера, нагрузку по устройствам. Пароли хранятся только на этом компьютере в зашифрованном виде.
Дополнительно
Включить доступ на MikroTik одной командой
Winbox или WebFig → New Terminal → вставьте (замените пароль) → Enter. Создастся пользователь только для чтения, а API откроется только для этого компьютера. Затем выберите способ «api», логин panda и ваш пароль.
