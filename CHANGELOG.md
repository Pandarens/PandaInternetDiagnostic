# Изменения

## v1.1.1

- Исправлена ошибка «'<=' not supported between instances of 'NoneType' and 'int'» при проверке с роутерами, которые не сообщают ширину канала соседних Wi-Fi сетей (Xiaomi и др.).
- Сбой второстепенного анализа больше не прерывает всю проверку; подробности ошибок пишутся в app.log.

## v1.1.0

- Доступ к роутеру прямо в программе: поля под конкретную модель, проверка подключения, подсказки, где взять пароль.
- Пароли хранятся зашифрованными (Windows DPAPI).
- MikroTik: подключение через API 8728/8729 без сертификата и готовый скрипт включения доступа.
- Новый вывод «Почему пропадает интернет»: виновник, уверенность, доказательства и закономерности по истории.
- Сон компьютера больше не считается обрывом.
- Отдельно фиксируются сбои DNS и частичная недоступность интернета.
- В момент каждого обрыва сохраняются сигнал Wi-Fi, загрузка канала и состояние роутера.

## v1.0.0

- Проверка интернета одной кнопкой: ответ простыми словами, шаги и текст для провайдера.
- Постоянное наблюдение: журнал обрывов с причиной, уведомления Windows, автозапуск.
- Диагностика роутера: завис, сам перезагружается, не тянет нагрузку, сломан DNS, конфликт адресов.
- Поддержка Xiaomi, MikroTik, Keenetic, ASUS, OpenWrt, TP-Link, Fritz!Box, Huawei 4G, UPnP, SNMP, ONT Huawei/ZTE.
- Анализ Wi-Fi эфира и подбор канала, нагрузка по устройствам, тест скорости и роутера под нагрузкой.
- Быстрые исправления: DNS, IP, сетевая карта, энергосбережение, сброс сети.
- Автообновление с GitHub без переустановки.
